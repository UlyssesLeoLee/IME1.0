# 欧几里得求最大公约数（Euclidean GCD）

- 资产 ID：`algorithm.math.euclidean_gcd`
- 类型：`algorithm`（算法）
- 分类：`math`
- 版本：`1.0.0`
- 状态：`DOCUMENTED`（知识卡已成文，尚未经人工审阅；本资产没有任何已认证的语言实现）
- 别名：`euclidean_gcd`、`gcd`、`最大公约数`、`辗转相除法`

## 一句话定位

反复用 gcd(a, b) = gcd(b, a mod b)，每次都把较大的数缩小，因此必然终止。

判断两个周期是否同余、约分分数、计算模逆元，都需要最大公约数这个基本量。

## 典型源文件形状

```rust
pub fn gcd(mut a: u64, mut b: u64) -> u64 {
    while b != 0 {
        (a, b) = (b, a % b);
    }
    a
}
```

## 适用条件

- 需要最大公约数本身（分数约分、周期分析、简化比例）
- 作为其它算法（扩展欧几里得、模逆元）的子步骤
- 输入是非负整数且规模适中
- 需要常数额外空间的迭代实现

## 反例

- 需要贝祖系数 s, t 使 sa + tb = gcd(a, b)——用扩展欧几里得算法
- 输入含负数——需先取绝对值（或用带符号的扩展版本）
- 输入是浮点数或有理数——本算法只对整数成立
- 只需要"是否互质"——同样用本算法，但可提前返回

## 并发风险

- 纯函数、无共享状态，天然线程安全
- 在多线程中并行计算多对数的 gcd 是常见用法（每个线程独立调用即可）
- 若把结果缓存进全局结构，更新需要同步；通常不需要缓存
- 无递归则无栈深风险（递归实现对斐波那契输入深度可达 O(log n)）

## 替代方案

- `algorithm.math.extended_euclidean` — 需要贝祖系数或模逆元时用扩展欧几里得。
- `algorithm.math.modular_exponentiation` — 需要在模意义下做幂运算时用模幂算法。

## 测试说明

- 与暴力枚举因子（交叉验证）对比
- 边界：gcd(0, 0) = 0、gcd(0, n) = n、gcd(n, n) = n
- 互质的一对数（结果为 1）
- 斐波那契相邻数（最坏情况的步数）
- 大数（u64 上限附近）
- 性质测试：断言 gcd(a,b) 同时整除 a 和 b，且 gcd(a/g, b/g) == 1

## 实现注意

- 优先标准库：Rust 有 `u64::gcd`（`num_integer` trait，Rust 1.x 起内置于 `std::num`），不要手写
- 复杂度：时间 O(log min(a, b))（最坏情况为斐波那契输入），空间 O(1)
- 稳定性：不适用
- 内存：常数
- 溢出：取余操作使参数单调递减，不会溢出；但若用 `a - b` 形式计算 gcd 则可能溢出
- 极端输入：0 与 0、u64::MAX、相邻斐波那契数
- 并发安全：纯函数，完全线程安全
- 限制：只对整数成立；不给出贝祖系数；不做模逆元
