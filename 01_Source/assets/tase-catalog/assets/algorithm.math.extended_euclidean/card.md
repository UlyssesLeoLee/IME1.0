# 扩展欧几里得算法（Extended Euclidean Algorithm）

- 资产 ID：`algorithm.math.extended_euclidean`
- 类型：`algorithm`（算法）
- 分类：`math`
- 版本：`1.0.0`
- 状态：`DOCUMENTED`（知识卡已成文，尚未经人工审阅；本资产没有任何已认证的语言实现）
- 别名：`extended_euclidean`、`扩展欧几里得`、`exgcd`、`贝祖系数`

## 一句话定位

在辗转相除的每一步同时维护系数，结束时得到贝祖等式，从而能求模逆元。

解同余方程 ax ≡ c (mod m)、求 a 在模 m 下的逆元、线性丢番图方程，都需要这一组系数。

## 典型源文件形状

```text
extended_gcd(a, b):                  // 返回 (g, s, t) 使 s*a + t*b = g
    if b == 0: return (a, 1, 0)
    (g, s1, t1) = extended_gcd(b, a mod b)
    return (g, t1, s1 - (a / b) * t1)

mod_inverse(a, m):                   // 要求 gcd(a, m) == 1
    (g, s, _) = extended_gcd(a, m)
    if g != 1: raise NotInvertible
    return s mod m
```

## 适用条件

- 求模逆元（扩展欧几里得、费马小定理）
- 解线性同余方程与线性丢番图方程
- 求有理数的分子分母（分数化简的推广）
- 中国剩余定理的构造步骤

## 反例

- 只需要 gcd——用普通欧几里得算法
- 模数是质数且 a 与模数互质——费马小定理 a^(m-2) mod m 更简单
- 只需要判断是否互质——普通 gcd 足够
- 输入是浮点数——本算法只对整数成立

## 并发风险

- 纯函数、无共享状态，天然线程安全
- 递归实现有栈深风险（斐波那契输入深度 O(log n)），迭代实现更好
- 在大批量计算中可按数据分片并行
- 若把结果缓存进全局表，需要同步

## 替代方案

- `algorithm.math.euclidean_gcd` — 只需要最大公约数时用普通版本。
- `algorithm.math.modular_exponentiation` — 模逆元也可用费马小定理配合模幂求解（模数为质数时）。

## 测试说明

- 断言 s*a + t*b == gcd(a, b)（用 i128 中转避免溢出）
- 边界：b = 0、a = 0、a = b
- 负数输入（符号要正确处理）
- 互质与不互质各一组（不互质时模逆元不存在）
- 与暴力枚举寻找系数（小数值）交叉比较
- 模逆元测试：断言 inv * a mod m == 1

## 实现注意

- 优先标准库/成熟库：Rust 标准库无扩展欧几里得；成熟 crate 有 `num-integer::extended_gcd`，引入前需核查许可
- 复杂度：时间 O(log min(a, b))，空间 O(1)（迭代版）或 O(log n)（递归版栈）
- 稳定性：不适用
- 内存：常数
- 溢出：系数 s、t 可能超出输入的位宽——用 `i128` 中转；`s1 - (a/b)*t1` 是溢出高发点
- 极端输入：a = 0、b = 0、负数、斐波那契相邻数（最坏步数）
- 并发安全：纯函数，完全线程安全
- 限制：只对整数成立；不互质时不存在模逆元；递归实现有栈深限制
