# 快速幂（平方求幂）（Exponentiation by Squaring）

- 资产 ID：`algorithm.math.fast_power`
- 类型：`algorithm`（算法）
- 分类：`math`
- 版本：`1.0.0`
- 状态：`DOCUMENTED`（知识卡已成文，尚未经人工审阅；本资产没有任何已认证的语言实现）
- 别名：`fast_power`、`binary_exponentiation`、`快速幂`、`平方求幂`

## 一句话定位

把指数写成二进制，base 的各次幂依次相乘，指数每右移一位就多乘一个平方因子。

计算 2^1000000 用连乘要一百万次乘法，快速幂只要约 20 次。

## 典型源文件形状

```text
fast_power(base, exp):              // 整数精确幂
    result = 1
    b = base
    while exp > 0:
        if exp is odd: result = result * b
        b = b * b
        exp = exp >> 1
    return result
```

## 适用条件

- 指数很大（几十位以上）
- 需要在模意义下求幂（配合模幂算法）
- 浮点幂运算需要更快收敛时（配合迭代细化）
- 矩阵幂、组合数计算的子步骤

## 反例

- 指数很小——朴素连乘更简单
- 结果需要精确且会溢出——必须改用模幂或大整数
- 浮点数场景——直接用 `powf` 即可，快速幂是整数算法
- 指数是 0 或 1——直接返回

## 并发风险

- 纯函数、无共享状态，天然线程安全
- 并行化收益有限（只有 O(log n) 步），不适合并行
- 大整数运算库通常不是线程安全的（内部可变缓冲区），跨线程要各自实例
- 若结果被缓存进全局结构，需要同步

## 替代方案

- `algorithm.math.modular_exponentiation` — 需要结果对 m 取模时必须用模幂，否则中间值会溢出。
- `algorithm.math.euclidean_gcd` — 两者都属于基础数论算法，常在同一题中先后出现。

## 测试说明

- 与朴素连乘（小指数）交叉比较
- 指数为 0、1、2
- 底数为 0、1、-1
- 大指数（如 10^18）的结果与朴素算法在可验证范围内一致
- 性质测试：断言 fast_power(b, e) == fast_power(b, e1) * fast_power(b, e2)（e = e1 + e2）
- 断言对 2 的幂次与移位一致

## 实现注意

- 优先标准库：整数快速幂可手写（约 5 行）；浮点用 `f64::powf`；模幂请用成熟库
- 复杂度：时间 O(log e) 次乘法，空间 O(1)
- 稳定性：不适用
- 内存：常数
- 溢出：这是最大的坑——中间值 b = b*b 极易溢出；整数精确幂必须检查溢出或改用大整数/模幂
- 极端输入：指数 0、底数 0（0^0 的约定要明确）、指数接近类型上限
- 并发安全：纯函数，完全线程安全
- 限制：整数精确幂会溢出；浮点不适用；大整数需要额外库
