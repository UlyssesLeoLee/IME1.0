## 1. 重构的原则

1. **行为零变化**：重构**只改结构**，不改行为。任何行为上的改动都要单独提出来（像这一轮的 D-93 / D-102 / D-103 那样，
   单独成条、单独验证、单独说明）。
2. **测试是契约**：重构前先确认相关测试**能钉住**现在的行为（红绿轮已经把这把尺子立起来了 ✓）。
3. **一次一段、文件所有权不重叠**：并行工人之间**不许动同一个文件**，否则合并会打架。
4. **每期都要能回退**：一个提交一个主题，`git revert` 就能单独退掉一期。
5. **不许「顺手优化」**：重构里混进行为变更 = 无法验收。这一期只搬代码、改名、拆函数。
