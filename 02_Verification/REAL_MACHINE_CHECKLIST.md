# 真机验收清单（0.3.1）

> 这份清单是给**人**看的：换上新 DLL 之后照着走一遍，每条写下「过 / 不过 / 什么现象」。
> 清单里的每一条都对应一个**已经写好的自动化测试**，但自动化测的是代码层；这里测的是**真实宿主里的手感**。
> 换 DLL 的方法在最后（要注销或重启）。

## 怎么换上新 DLL

1. 先把旧的装卸掉（**必须先卸**，不然旧 DLL 还被系统占着）：
   - 控制面板 → 程序 → 「IME1.0 / 编程输入法」→ 卸载；
   - 或者直接跑 `E:\IME1.0\01_Source\dist\ProgrammingIME-0.3.1-win-x64-setup.exe`（安装向导会自己发现旧版并提示先卸）。
2. 装新的 0.3.1（**未签名**：360 安全卫士可能拦它，需要在 360 里加信任，或者用管理员身份运行）。
3. **注销或重启**（旧 DLL 被系统占用时安装程序会返回 3010 = 需要重启）。
4. 回来之后确认一下：在「设置 → 时间和语言 → 语言和区域 → 语言选项」里应该能看到「IME1.0 中文 / IME1.0 English / IME1.0 日本語」三个语言。

## 四之二、代码输入 / 自然语言输入（0.3.2 的新口径）

> **出厂是「代码输入」**：输入法**一个字符都不吃**，代码原样进编辑器；候选列表只是**预览**，**不弹面板**，数字键仍归编辑器。
> **Ctrl+F12**（或 Alt+F1）切到**自然语言输入**：打字开组合，候选列表接管数字 / Tab / 空格 / 回车。
> **Ctrl+F12 之前是「切换输入法」**——旧 DLL 上按它会去切输入法，不是切模式。

| # | 做什么 | 怎么算过 |
|---|---|---|
| 4.2.1 | 装上 0.3.2 后注销/重启，在记事本里打 `fn main` | 字符**原样**进文档（没有候选面板弹出来） |
| 4.2.2 | 按 **Ctrl+F12** | 面板**不弹**（模式变了，但面板只在你要求时才出现） |
| 4.2.3 | 再打 `wo` | 候选**面板**弹出来（自然语言输入里，列表就是面板） |
| 4.2.4 | 按 **1** | 上屏的是「**我**」，**不是** `w1o`（这一条是 2026-11-12 你报的那个问题） |
| 4.2.5 | 再按 **Ctrl+F12**，打 `wo` | 候选面板**不弹**了，`wo` 原样进文档 |
| 4.2.6 | 在**密码框**里按 Ctrl+F12 | 模式**不变**，键**留在编辑器**（那里什么都不收集） |
| 4.2.7 | 面板开着时，在文档里打字 | 面板**收工**（点区域外的点击我们收不到，所以是下一次按键时消失） |

## 已知在真机之外的东西（别指望清单能测出来）

* **TASE 的队列链路**（客户端交作业 → Hub 排队 → worker 算 → 回报）：本轮已用**真 Hub + 真帧 + 内存管道**测通，但**真命名管道**在本机跑不起来（D-85：Hub 打印的管道名它自己开不了）——这条要单独验。
* **成本基准**：本地候选延迟 p95 **28.5 µs**（预算 50 ms）、一次典型请求 96+200 token（价格用**样例表**算的，换成你的价目表才是你的数）。
* **30 分钟离线长稳**、**多屏/DPI/读屏**、**真实服务商的账单**：设计书的用例里都还没执行。
